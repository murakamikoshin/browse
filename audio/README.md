# 音の素材を置く場所

ここに mp3（または ogg）を置いて `python3 tools/build_audio.py` を叩くと、
`game.html` に data URI で焼き込まれます。**artifact では外部の音声ホストが
遮断される**ので、外に置いたままでは鳴りません。焼き込む以外の道はありません。

## 入れるファイル

置いたものだけが差し替わります。無いものは合成音のままです。

| ファイル名 | 何の音 | 長さの目安 | 継ぎ目 |
|---|---|---|---|
| `nami.mp3` | 夜の港の波。静かな寄せ波 | 40〜90秒 | 要ループ |
| `kaze.mp3` | 軒下の風。玄関の外 | 30〜60秒 | 要ループ |
| `heya.mp3` | 家の中の空気。低い持続音 | 30〜60秒 | 要ループ |
| `asa.mp3` | 朝の海。波より高いところが開いた音 | 40〜90秒 | 要ループ |
| `ki.mp3` | 木。移動したときの小さい音 | 〜0.3秒 | 不要 |
| `kami.mp3` | 紙。控えを受け取る、封を剥がす | 〜0.5秒 | 不要 |
| `ko.mp3` | 線香が一本尽きる | 〜0.8秒 | 不要 |
| `fusuma.mp3` | 襖を引く音 | 〜1.2秒 | 不要 |
| `rin.mp3` | おりん。**第四封の一行目だけ**で鳴る | 〜6秒（余韻込み） | 不要 |

## 大きさ

artifact の上限は 16MB で、data URI にすると元の 1.33 倍になります。
**素材の合計を 3MB 以内**に収めてください。モノラル・64〜80kbps で十分です。
上の一式なら 1.5MB 前後に収まります。

    ffmpeg -i in.wav -ac 1 -b:a 80k -ar 44100 nami.mp3

## 音楽について

**全編に流す BGM は入れないほうがいい**と考えています。この夜に音楽は流れていません。
鳴っているのは部屋と海だけで、そこに曲を乗せると、帳場の沈黙が演出になります。
入れるなら第七章の読み上げのあと（`asa.mp3` の代わり）だけにしてください。

## 素材の出どころ

規約は落とすときに各サイトで確認してください。ここに書いたのは目安です。

## 音楽

いまは音の合成で、都節音階の単音を間を空けて置いています（旋律も拍もありません）。
差し替えたい場合は、この二本を置いてください。**置くと合成音は鳴らなくなります。**

| ファイル名 | いつ鳴るか | 長さの目安 |
|---|---|---|
| `music_yoru.mp3` | 通夜の夜のあいだ（第1〜6章） | 2〜4分、要ループ |
| `music_asa.mp3` | 出棺の朝（第7章と封） | 2〜4分、要ループ |

**曲は「止められる」ことが仕事です。** 重要な行では自動で音量が下がり、
第四封では鈴のあいだ引きます。だから、音数が少なく、間の空いた曲を選んでください。
旋律が立っている曲を置くと、下がったことに気づけなくなります。
