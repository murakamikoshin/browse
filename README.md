# レテ精算所 — Lethe Settlement Office

支払った額によって、同じ文章が別の話になるノベルゲーム。

## 設計の柱

**1. 支払いは開始前の一度きり。追加課金はできない。**
事前に開示するのは3点だけ ——「上限は ¥1,000,000」「返金はない」「開始後の追加はできない」。
いくら必要になるのかは、最後まで明かされない。足りているか分からないまま進むことが体験の中心。

**2. 無料で最後まで遊べる。**
ベース層だけで一本の短編として完結していること。課金層は「欠けた情報」ではなく「別の読み」。
課金しないと話が分からない虫食いにはしない。

**3. 二つの軸**

| 軸 | 内容 |
|---|---|
| 解像度 | 支払額に応じて、同じ場面の文章が書き換わる。読めない行は塗り潰される（値段は表示しない） |
| 残高 | 支払額がそのまま所持金になる。道中で「記憶」を買うと減る。買値は買ったあとに判明する |

塗り潰しは世界観の一部（この街では記憶が売買される）であって、課金の督促ではない。

## 現在の内容

- `index.html` — 冒頭一場面。支払額で文章そのものが書き換わる仕組み
- `door.html` — 金額の刻み → 購入 → 扉の開封 → 不足額 → 精算書

どちらもビルド不要でブラウザで直接開ける。
金額の切り替えは**制作側の検証用**で、本編には存在しない。

詳細は [SPEC.md](SPEC.md)。
