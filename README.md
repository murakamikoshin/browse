# 帳場 — 支払った額で、同じ夜が別の話になるノベルゲーム

支払いは開始前の一度きり。追加課金はできない。
**いくら必要になるのかは最後まで明かさない。** 足りているか分からないまま進むことが体験の中心。

## 金の換算

**この町の金は、現実の百倍。** 物語の中の額はすべて「この町の金」で書かれる
（兄が貯めた金百万円、手帳に引かれた線、朝に読み上げられる額）。
現実に払うのはその百分の一で、**金九千円までは支払いが起きない。**

| 包む額（この町の金） | お支払い | 帯 |
|---|---|---|
| 金零円 〜 金九千円 | **なし** | 帯1・帯2（19段、エンディング28通り） |
| 金一万円 〜 金九万円 | ¥100 〜 ¥900 | 帯3（エンディング27通り） |
| 金十万円 〜 金九十万円 | ¥1,000 〜 ¥9,000 | 帯4（エンディング27通り） |
| 金百万円 | **¥10,000** | 帯5（エンディング3通り） |

事前に開示するのはこの三点だけ ——「上限は金百万円、お支払いで¥10,000」
「この町の金はあなたの百倍。金九千円まではお支払いなし」「返金はない、開始後に足せない」。

支払いが始まる金一万円は、**帯3（気づいたのに届かない帯）の入口とちょうど重なる。**
無料の人は気づかないまま幸せに終われて、金を払うと気づいてしまう。
決済には固定費があるので、実額¥100を下回るものは作らない（¥1では手数料で赤字になる）。

無料で最後まで遊べて、無料でも一本の短編として完結する。
課金層は「欠けた情報」ではなく **別の読み**。低い層の本文は虫食いではなく、
それ自体で筋の通った**誤読**になっている。伏線とは、誤読していた証拠のこと。

## 二つの軸

| 軸 | 決まり方 | 効くもの |
|---|---|---|
| **帯**（解像度） | 支払額だけで決まる。帯1〜帯5 | 本文の書き換え。主人公の自己認識 |
| **残高** | 支払額 − 道中で買った額 | 最後に開く封の数。主人公が知らない他人の秘密 |

- 支払いの刻みは可変（¥100刻み→¥1,000→¥10,000→¥100,000）で **38通り**
- 帯の境目は ¥1,000 / ¥10,000 / ¥100,000 / ¥1,000,000
- 購入は9件、比率価格（安3% / 中8% / 高20% / 番外45%、合計118%）。**買える上限は99%** なので
  残高が支払額の1%を下回ることはない。したがって帯4は必ず1封、帯5は必ず2封が開く
- 封は4枚：第一封 ¥1,000 凪の真実 / 第二封 ¥10,000 世界の仕組み / 第三封 ¥100,000 兄の真実 /
  第四封 ¥1,000,000 あなた自身。**残高がその額以上なら開く**
- エンディングは **85通り**。支払額×開封数の格子は96あるが、買える上限が99%なので
  ¥100,000以上は必ず1封、満額は必ず2封が開く。**11の組には誰も到達しない。**
  ED番号は到達する85組に詰めて振る。ED-01 が ¥0、ED-85 が ¥1,000,000 開封4

## 書き方の規則（全部これで判定している）

- 帯 = 主人公の自己認識 ／ 封 = 主人公が知らない他人の秘密
- 本文は事実まで。因果は封で
- **売るのは事実だけ。解釈は売らない**
- 章をまたいだ参照は、事実を一度自分で述べる（自由な移動で順番が崩れるため）
- 封の文は自己完結する。購入でしか手に入らないものは繰り返さない
- 封は買った人と買わなかった人の両方に効かせる
- **最終行は開封数も購入の有無も知らない。** 同じ支払額なら全員が同じ一行を読む
- ¥0 には封の値段も不足額も見せない。襖の前にも立たせない

## 状態

**本文とデータは全部揃っている。** 第一章から第七章、四つの封、最終行38本、ED名85個、
夜の行動24本、手を動かすところ13箇所、章の引き3箇所、帳場さんの帳5節。
道具九本と `verify.mjs` `playtest.mjs` がすべて不備0件で通る。
満額の通しで ED-85「わたしの帳」まで到達する。

- **名札** 「」で始まる行にだけ話者を出す。地の文と封には出さない
- **ふりがな** 辞書を積んで描くときに当てる。原稿には埋め込まないので指せる語句が壊れない
- **音** その場で合成する。**環境音（海・風・部屋）＋音楽（都節音階の単音と持続音）＋効果音。**
  旋律も拍も作らないが、無音にはしない —— 無音が効くのは、鳴っているものを止められるから。
  重要な行と第四封の鈴のあいだは音楽が引く。鈴は第四封の一行目だけ。
  次の行へ送るたびに**送り**が鳴る（毎行鳴るので、いちばん小さく短い木の音）。
  選ぶと**合図**が鳴る
- **印** 音の付く行は33。**翳**（含みを持たせた行、低く怪しいうねり）が20、
  **重**（この夜の要、低く一打）が13。
  **どちらも帯で書き換わらない行にしか付けない。** 書き換わる行に音を付けると、
  どこが伏線かを音で教えることになり、無料の画面が「印の付いた穴だらけの話」に見える。
  `tools/build_marks.py` が機械で弾く
- **引き** 包んだ直後に朝の読み上げを四行だけ先に見せる（コールドオープン）。
  この夜の終わりに自分の額が読まれることが、最初から見えている
- **間** 額を読む前に1.6秒、最終行のあと1.8秒。本文に「また、間。」と書いてある所で実際に止まる
- **警告** 残高が四分の一を切ると、帳場さんが一度だけ態度で言う。額は言わない
- **買う道は必ず通る** 金一万円以上（＝お支払いのある額）を包んだ人は、
  帳場の机（帳場の奥）を一度も通らずに朝を迎えられない。自分で夜を終えるときは
  先に机への道を見せ、線香が尽きて朝になるときは机を通してから渡す。
  買えることを知らないまま終わる道が実際にあったため。`playtest.mjs` が毎回検査する
- **夜の順番** 五つの場所に章番号は付けない（歩いた順で番号が前後すると辻褄が合わない）。
  札は「通夜　港」のように出す。順番を持つのは夜明けと翌朝だけ。
  **仏間を通るまで、港・帳場の奥・玄関の外へは歩けない。** 兄の顔を見る前に
  「あの日の海」を読むことになると、話の順が壊れるため
- **手を動かすところ** 二択はどちらを選んでも先へ進む。前は片方が必ず同じ選択肢に戻ってきたので、
  そちらが「押しても何も起きない側」だと分かってしまい、選ぶ意味が無くなっていた
- **書体** クラフト明朝（アトリエこたつ）。作品が使う862字だけに絞って焼き込む（403KB）。
  ふりがなは Zen Old Mincho のまま。小さい字は掠れていないほうが読める
- **画面の並び** 題 → 説明三枚（額のこと／夜のこと／読むときのこと）→ 支払い → 確認 → 本編。
  どの画面も一枚に収まり、**頁は動かない**（`html,body{overflow:hidden}`）。中で送るのは本文の窓だけ。
  題からは 包む／帳を見る／遊び方／設定 の四つ。説明はどこからでも戻れる
- **語注** 破線の引いてある語を押すと、辞書の意味だけが出る。作品の側の意味は書かない。
  買える語句の札の中には入れない（指すのと押すのがぶつかるため）。
  **呼びかけ（さん・様・ちゃん）が続く語には出さない。** 凪さん は人の名前で、凪いだ海 は天気
- **帳** 見た結末を貯めて並べる画面。85行あり、見た分だけ名が出る。まだの行は罫線だけ。
  見た行を押すと、**その朝に読んだ最後の一行**と、
  **同じ額から行ける朝があと何かある**かが返る（額も開封数も、どう買えばそうなるかも出さない）。
  下に **手がかり**が並び、朝を一つ見るごとに一つ増える（全15本）。
  **どの額で何番が出るかは書かない**（次にいくら包むかの手がかりになるため）。
  包む前の画面（一度でも朝まで行った人にだけ）と、ED札の横から開く。
  ここに **帳場さんの帳** が五節あり、5 / 15 / 30 / 50 / 85 で一節ずつ開く。
  帳場さんは「何を知っているか」ではなく「何をしたか」だけを書く。だから封の中身は漏れない
