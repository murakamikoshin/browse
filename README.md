# 帳場 — 支払った額で、同じ夜が別の話になるノベルゲーム

支払いは開始前の一度きり。追加課金はできない。
事前に開示するのは3点だけ ——「上限は ¥1,000,000」「返金はない」「開始後の追加はできない」。
**いくら必要になるのかは最後まで明かさない。** 足りているか分からないまま進むことが体験の中心。

無料で最後まで遊べて、無料でも一本の短編として完結する。
課金層は「欠けた情報」ではなく **別の読み**。低い層の本文は虫食いではなく、
それ自体で筋の通った**誤読**になっている。伏線とは、誤読していた証拠のこと。

## 二つの軸

| 軸 | 決まり方 | 効くもの |
|---|---|---|
| **帯**（解像度） | 支払額だけで決まる。帯1〜帯5 | 本文の書き換え。主人公の自己認識 |
| **残高** | 支払額 − 道中で買った額 | 最後に開く封の数。主人公が知らない他人の秘密 |

- 支払いの刻みは可変（¥100刻み→¥1,000→¥10,000→¥100,000）で **38通り**
- 帯の境目は ¥1,000 / ¥10,000 / ¥100,000 / ¥1,000,000
- 購入は9件、比率価格（安3% / 中8% / 高20% / 番外45%、合計118%）。**買える上限は99%** なので
  残高が支払額の1%を下回ることはない。したがって帯4は必ず1封、帯5は必ず2封が開く
- 封は4枚：第一封 ¥1,000 凪の真実 / 第二封 ¥10,000 世界の仕組み / 第三封 ¥100,000 兄の真実 /
  第四封 ¥1,000,000 あなた自身。**残高がその額以上なら開く**
- エンディングは **85通り**。支払額×開封数の格子は96あるが、買える上限が99%なので
  ¥100,000以上は必ず1封、満額は必ず2封が開く。**11の組には誰も到達しない。**
  ED番号は到達する85組に詰めて振る。ED-01 が ¥0、ED-85 が ¥1,000,000 開封4

## 書き方の規則（全部これで判定している）

- 帯 = 主人公の自己認識 ／ 封 = 主人公が知らない他人の秘密
- 本文は事実まで。因果は封で
- **売るのは事実だけ。解釈は売らない**
- 章をまたいだ参照は、事実を一度自分で述べる（自由な移動で順番が崩れるため）
- 封の文は自己完結する。購入でしか手に入らないものは繰り返さない
- 封は買った人と買わなかった人の両方に効かせる
- **最終行は開封数も購入の有無も知らない。** 同じ支払額なら全員が同じ一行を読む
- ¥0 には封の値段も不足額も見せない。襖の前にも立たせない

## 状態

**本文とデータは全部揃っている。** 第一章から第七章、四つの封、最終行38本、ED名85個、
夜の行動24本。道具七本と `verify.mjs` がすべて不備0件で通る。
満額の通しで ED-85「わたしの帳」まで到達する。

- **ふりがな** 辞書を積んで描くときに当てる。原稿には埋め込まないので指せる語句が壊れない
- **音** その場で合成する。旋律は置かない。鈴は第四封の一行目だけ

### 残っているもの

1. **画像 18枚。** 制作者が用意する。いまは仮の図形。仕様は `ASSETS.md`
2. **音の素材（任意）。** いまは合成音で鳴る。差し替えたければ `audio/README.md`
3. **決済の実装。** サーバでの購入検証が必須。¥100の下限と手数料、
   ¥1,000,000をカード1回で通すのは個人与信を超えるため非カード手段が事実上必要
4. **法務まわり。** 特定商取引法に基づく表記、利用規約、プライバシーポリシー。
   返金しない・開始後に足せないという条件は、事前に読める場所に置く必要がある
5. **演出順。** `SPEC.md` は「エンディング → 余韻 → スタッフロール → 見たい人だけが開く精算書」
   としているが、いまは最終行とED札が同時に出る。札は開封数とED名だけで額は出さないので
   破綻はしていないが、仕様どおりではない
