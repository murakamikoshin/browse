# 出すために要るもの

`README.md` の「残っているもの」を、**決済・法務・内容の断り**にしぼって書き下したもの。
金額はすべて**現実の円**で書く（作品の中の「この町の金」は、現実の百倍）。

---

## 1. いちばん先に決めること — この作品は「どこで」売るのか

**いま `game.html` は一枚の静的ファイルで、封の本文も帯5の書き換えも全部その中に入っている。**
つまり、**このままでは売れない。** 開発者ツールを開けば、包まなくても全部読める。

出し方は三つある。どれを選ぶかで、以下の作業がまったく変わる。

### 甲　作品ごと売る（itch.io / BOOTH / Gumroad）
- 「ほしい額を決めて払う」（pay what you want）に対応している場を使い、
  **払った額を鍵にして、その帯のファイルを渡す**
- サーバは要らない。決済も返金も、その場の規約に乗る
- **弱点**：包む場面が作品の外に出る。「額を決めるところ」が体験の中心なのに、そこが
  itch.io の決済画面になる。買ったあとに帯を変えられないので、二周目は買い直し
- 作業量：小。特商法表記はプラットフォーム側で足りることが多い（要確認）

### 乙　薄いサーバを一つ立てる（推奨）
- `game.html` から**封の本文と帯4・5の書き換えだけ**を外に出す
- 支払い（Stripe Checkout など）→ サーバが検証 → その額ぶんの本文だけを返す
- 包む場面は作品の中に残る。二周目も、額を変えて買い直せる
- **要件**：
  - 客側で `S.paid` を書き換えても、返ってくる本文は変わらないこと
    （いま `window.__dev` から何でも触れる。**本番では消す**）
  - 返すのは「その額で開く分」だけ。全部返して客側で隠す、は不可
  - 領収の記録を残す（特商法・税）
- 作業量：中。サーバ一本、決済一本、鍵の管理

### 丙　無料のまま出す
- いまの形のまま。金の話は作品の中の話として残り、現実の決済はしない
- **作業量：ゼロ。** 法務もほぼ要らない（内容の断りだけ）
- 「額で読み方が変わる」という中心は、**現実の金を払わなくても成立する**
  （包む額を選ぶ体験そのものは残る）。無料で出して反応を見る、という選択は十分ある

> **決めていないうちは、丙のままにしておくこと。**
> いま画面に「これは制作中の試作です。実際の決済は行われません」と出しているのは、
> 丙の状態を正しく言っている。ここを外すのは、甲か乙が動いてから。

## 2. 乙を選んだときに要るもの

### 決済
- [ ] 決済事業者（Stripe / KOMOJU / PayPal など）と契約
- [ ] **サーバ側で検証**。客が送ってきた額を信じない
- [ ] 38段のうち、現実の支払いが発生するのは **金一万円（¥100）以上の28段**。
      金九千円までは無料（`README.md` の表）
- [ ] 同じ人が額を変えて買い直せること（二周目の設計がそうなっている）
- [ ] 通信の失敗で「払ったのに読めない」が起きないこと。**払った記録が先、本文は後**

### 客側から消すもの
- [ ] `window.__dev`（`STEPS` `jump` `begin` `chapter` `queue` `log` ほか全部）
- [ ] 「検証用：指せる語句を光らせる」の切り替え（`.dev` の欄）
- [ ] 封の本文・帯4/5の書き換え・最終行38本を、初期の `game.html` から抜く

### 法務
- [ ] `docs/legal/tokushoho.md`（特定商取引法に基づく表記）を埋めて公開
- [ ] `docs/legal/terms.md`（利用規約）を埋めて公開
- [ ] `docs/legal/privacy.md`（プライバシーポリシー）を埋めて公開
- [ ] **返金**：いま画面に「返金はありません」と出している（`HINTS`）。
      デジタルコンテンツの性質上そう書けるが、**特商法の表記と食い違わせない**こと
- [ ] **資金決済法**：作品の中の「この町の金」は、預り金でも前払式支払手段でもない
      （残高を持ち越さない・払い戻さない・その一回の読みにしか使わない）。
      そう読めるように規約に書く
- [ ] **景品表示法**：額と結末の対応は「多く払うほど良い結末」ではない。
      画面でもそう言っている（「同じ額でも、別の朝になります」）。
      宣伝文でも「課金するほど良い」と読める書き方をしない
