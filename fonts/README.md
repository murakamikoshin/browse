# 書体を置く場所

`クラフト明朝`（アトリエこたつ）の OpenType ファイルをここに置いて
`python3 tools/build_font.py` を叩くと、**この作品で実際に使う文字だけに削ってから**
`game.html` に焼き込みます。

    fonts/craftmincho.otf   ← ここに置く（.ttf .otf .woff2 のどれでも）

## なぜ削るのか

- **artifact では外部のフォントを読めません。**CSPで fonts.gstatic.com 以外は遮断されるので、
  焼き込む以外に道がない
- 日本語フォントは丸ごとだと数MB。base64にすると1.33倍になり、16MBの上限を圧迫する
- この作品が使う文字は決まっている（本文・ふりがな・画面の言葉で1,000字前後）。
  そこだけ残せば **数百KB** に収まる

## 検査

`tools/build_font.py` は、**焼き込む前にフォントに無い文字を全部並べます。**
クラフト明朝は第一水準漢字（2965字）までなので、第二水準の字（柩・襖・框・鍮・鋏 など）が
入っていない可能性があります。無い字は落ちずに、CSSの次の書体（Zen Old Mincho）で出ます。
ただし**書体が混ざるので、無い字が多いようなら使う場所を絞ってください。**

## ふりがな

ふりがなは小さく出るので、かすれのある書体だと潰れます。
既定では**ふりがなだけ Zen Old Mincho のまま**にしてあります。
クラフト明朝で統一したい場合は `--ruby` を付けてください。

## このリポジトリに .otf は置いていない

**置きません。**`.gitignore` で弾いてあります。
このリポジトリは公開されているので、`.otf` をそのまま置くと
規約が禁じている「フォントファイルのみの再配布」に当たります。

作品が使う862字ぶんは `game.html` に焼き込み済みなので、**遊ぶだけなら要りません。**
本文を書き換えて焼き直したくなったときだけ、
[配布元](https://free-fonts.jp/craftmincho/) から取って `fonts/craftmincho.otf` に置いてください。

同梱の規約原文は `fonts/craftmincho-readme.txt` に写してあります。

## ライセンス

配布元の規約に従ってください。調べた範囲では個人・商用とも無料、
**ゲームへの埋め込みも可**、ただし**フォントファイルのみの再配布・販売は禁止**です。
ここでやっているのは作品への埋め込みであって、ファイルの再配布ではありません。
ダウンロードに同梱される規約の原文を、公開前に必ず確認してください。
